# Student Management System

A Spring Boot application for managing student records with REST API endpoints.

## Features
- Add new students
- Get all students
- Update student information (PATCH)
- Delete students

## Technologies Used
- Spring Boot
- Spring Data JPA
- MySQL/H2 Database
- REST API

## Frontend
- HTML, CSS, JavaScript
- Tailwind CSS

## API Endpoints
- `GET /students` - Get all students
- `POST /add-student` - Add a new student
- `PATCH /update-student/{studentId}` - Update student details
- `DELETE /students/{studentId}` - Delete a student
